## Confirmed defects fixed in the cleanup

- #634: predictable browser-history database snapshot path could follow a pre-created link in an elevated process. Use a random atomically created temporary directory; own it through the snapshot cache and delete old sidecars on refresh.
- #721: replace custom predictable Task Scheduler staging filenames with NamedTempFile, held open through the scheduler call and deleted on every return path.
